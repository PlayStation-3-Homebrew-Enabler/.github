## ⚡ Quick Start

1. Identify the PS3 model and installed system software version under Settings → System Settings → System Information.
2. Check the official PS3HEN compatibility list and determine whether the required Hybrid Firmware (HFW) installation applies.
3. Follow the PS3HEN installation instructions for the exact firmware and console configuration.

After installation, the PS3 XMB provides access to the HEN enable function and supported homebrew features.

## 📥 Installation Guide

### 1. Identify the Console Configuration

Open Settings → System Settings → System Information and record the installed system software version.

Identify whether the console uses CEX retail or DEX debug firmware.

### 2. Prepare Hybrid Firmware

If the installation procedure requires HFW, obtain the matching release specified by the PS3HEN installation documentation.

Verify the downloaded PUP file against the published checksum before installation.

### 3. Install PS3HEN

Follow the official PS3HEN installation guide for the selected firmware version.

The documented installation process may use the PS3 browser, PS3Xploit installation resources, and a USB-based package installation path.

### 4. Enable HEN

After installation, return to the XMB and use the HEN enable entry.

Wait for the system to complete the activation process before launching homebrew applications.

### 5. Verify the Environment

Confirm that the HEN entry is available and that supported package and homebrew functionality can be accessed.

## ❓ FAQ

### What is PS3HEN?

PS3HEN stands for PlayStation 3 Homebrew Enabler. It provides homebrew functionality on PS3 consoles through a HEN and Hybrid Firmware environment.

### Does PS3HEN support PS3 Slim and Super Slim?

Yes. PS3HEN is designed for all PS3 model families, including Slim and Super Slim consoles.

### What is the difference between HEN and CFW?

HEN is a homebrew-enabling environment installed through its supported HFW process. Traditional CFW is a different firmware modification method with separate hardware and firmware compatibility requirements.

### Which firmware versions are supported?

The project README lists HEN support for CEX OFW 4.80–4.82 and multiple HFW releases through 4.93.1. Check the release documentation for the exact configuration.

### How do I update PS3HEN?

Use the update function and procedure documented by the project. Confirm the installed firmware and HEN release before applying an update.
